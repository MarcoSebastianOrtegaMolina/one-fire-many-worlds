# Aportes de Marco Sebastián

Esta carpeta es tuya. Sube aquí lo que encuentres: PDF, documentos, imágenes, capturas o notas.

**Para subir un archivo:** toca «Add file», luego «Upload files», arrastra tus archivos y toca
«Commit changes». No hace falta instalar nada.

**Para escribir una nota:** toca «Add file», luego «Create new file», ponle un nombre que termine en
`.md` (por ejemplo `detectores-de-humo.md`) y copia la plantilla de `aportes/PLANTILLA.md`.

Cuando subas algo, anótalo en un renglón de `BITACORA.md`, y si es una fuente nueva, en `FUENTES.md`.
